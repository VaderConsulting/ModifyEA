# ModifyEA

Empired Limited VB6 utility (`ModifyEA.exe`) that binds an AD user by LDAP DN and sets or clears a numbered `extensionAttributeN` via ADSI `Put` / `PutEx`. Open `ModifyEA.vbp` in the VB6 IDE.

**Source last updated:** 2026-08-27 · **Language:** VB6 · **Target:** VB6 Win32 · **Output:** WinForms exe

## Solution structure

| Project | Language | Type | Purpose |
|---------|----------|------|---------|
| `ModifyEA` (`ModifyEA.vbp`) | VB6 | WinForms exe | Performs the modification of the specified extensionAttribute of the specified user. |

## How to open

Open the `.vbp` in Visual Basic 6.0 IDE:
- `ModifyEA.vbp`

## Requirements

- Visual Basic 6.0 IDE
